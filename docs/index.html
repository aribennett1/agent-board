Stop polling. Wake a bot only for real work.

Agent Board is a small, event-driven task board for a team of AI coding bots and one human.

View on GitHub

The problem

Bots on timers poll. Most wake-ups find nothing, and each one pays for a full context load.

  • It burns usage. Idle wake-ups are the biggest line item.
  • Work gets lost. Nobody owns a handoff, so tasks stall between bots.
  • State drifts from the issue tracker and from GitHub.
  • You become the scheduler, chasing bots and watching for loops.

The approach

Scripts do everything they can for free. A bot is woken only when there is real work.

webhooks and notes→SQLite events→real work?→wake the owner·otherwise stay silent
  • Event-driven, scripts as backstops. GitHub and Linear webhooks, notes and state changes are events. An hourly tick catches the rest.
  • Authorship enforced in SQLite. Notes are append-only and a trigger refuses the wrong author.
  • Liveness check-ins. A silent bot gets one re-wake, then a card for you.
  • Hop limits. Two review rounds with no pass hands the task to the human.
  • Drift check against the tracker and GitHub.
  • Weekly bottleneck report of wakes, tokens, re-wakes and waits.
  • One inbox for the human. A red dot in the tab, a microphone in every text box, and every box can wake your assistant. The board polls a content hash every 10 seconds and swaps in only what changed, without reloading the page.

Quick start

git clone https://github.com/aribennett1/agent-board
cd agent-board
npm ci
npm start   # http://localhost:8787

Needs Node 22.18 or newer. All settings are environment variables with defaults; see .env.example.

Security

The board has no login. Run it behind an auth proxy such as Cloudflare Access and never expose it directly. The wake webhook URL and secret stay on the server and are never committed.
